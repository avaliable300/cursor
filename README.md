# 固定 128 字节循环日志示例

本项目提供一个简单的 C 语言日志库，支持：
- 标准输出（带可选颜色）
- 普通文本文件输出
- 固定 128 字节记录的循环日志文件（到达最大行数后从第一条覆盖）

## 构建

```bash
make
```
生成可执行程序 `app`。

## 运行

```bash
./app
```
会生成：
- `normal.log`：普通文本日志
- `rolling.log`：每条记录固定 128 字节的循环日志（100 条记录上限）

## 关键 API

- `log_add_fp(FILE *fp, int level)`：添加普通文件日志回调
- `log_add_rolling_fp(FILE *fp, int level, size_t max_lines)`：添加固定 128 字节记录的循环日志回调

注意：
- 建议以 `"w+b"` 打开循环日志文件，便于随机写入。
- 每条循环日志严格 128 字节，最后 1 字节固定为换行符 `\n`，其余不足部分以空格填充；超长内容会被截断以保证固定长度。

## 示例

参见 `main.c`，示例中会写入 150 条日志，其中循环日志 `rolling.log` 只保留最近 100 条（按固定记录槽位覆盖）。
